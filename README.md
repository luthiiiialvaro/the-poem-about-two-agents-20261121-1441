A short poem about agency — the power to choose and to act — written by a
program. `main.ts` (Node 22, standard library only, no network) reads
`poem.txt`, checks it is 1–280 characters, and writes it to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`).

The poem is about two agents agreeing on one plan: one draws the map, the
other holds the door, and the choice itself lives in the space between them —
agency not owned by either, but made real by their agreement.

## Run

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
cat out/entry.txt
```
